# 第三问最小主干

**主线：新预报改变缺口判断 → 判断是否值得付1.5倍价增购 → 储能吸收剩余误差 → 最终合同与应急分别结算。**

- 输入：附件1的144段电价；附件2的历史/当前负载与光伏；附件3已经发布的0/6/12/18时未来24个整点光伏预报。
- 决策：0时原合同g永久冻结；后三次只改未交付合同a与储能规则；十分钟执行只响应当前实际。
- 模型：最多8个历史同日联合残差情景，日内固定源日、更新预报版本残差；共同合同+共同低维储能反馈；真实SOC固定阶段初值；虚拟次日表示末态价值。
- 收费：主版J=Σpg+Σp[1.5(a−g)^++0.5(g−a)^+]+5Σpe；每段最终a相对g只计一次。主策略a>=g；退款口径另算。
- 物理：kW除6变kWh；S'=S+0.9c−d/0.9；S在1200–10800；充放各≤833.333...；逐段互斥；1/1起连续不重置。
- 实施：发布时优化剩余一天，当前版本延续至日末的近似；实际下次发布再重算。候选与旧策略在相同情景/S/尾部上经投影比较，不能根据真实未来选策略。
- 输出：334天result3四表；g原计划、a最终有效合同分开；四指定日表1–3；预报时刻的价值分析。
- 解释：区别“预报更准”“控制更好”“改单省钱”；不能预设Q3必胜Q2，不能编造其他时刻预报。

**最容易漏：**6时首预测是7时；6时第一可改段是06:00–06:10；首小时锚点已观测；当前段实际不进入合同决策；0时误差参考整日冻结；不能用0时PV残差替代新版残差；不能重算过去费用；调整表不是增减量；日总费不重复相加；18时不直接删除；年底无次年实际；限时可行不叫最优；先短测、固定参数、再全年。
