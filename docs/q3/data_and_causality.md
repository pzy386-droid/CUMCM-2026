## 2. 从小时预报重构十分钟曲线

本版固定采用线性插值的**右端代表值**：发布时间 τ 的锚点为该时刻刚结束区间的已观测光伏功率，连接 τ+1,...,τ+24 的小时预报；在每个十分钟右端取值，然后除以 6 得段电量。它不是把瞬时点误叫小时平均，也不声称插值获得了真实高频信息。

例如 τ=6，已知锚点 60 kW，7 时预报 120 kW，则 06:00–06:10 代表功率 70 kW，段能量 70/6 kWh；06:50–07:00 为 120 kW、20 kWh。禁止直接将 120 填到六个段的电量中。锚点来自 05:50–06:00 已完成段，不来自 06:00–06:10 未来值。

0 时锚点取上日最后一段观测；1/1 没有此前观测时以本次提前 1 小时预报作锚点的确定性冷启动规则，记录来源。禁止用尚未发生的当日实际填首小时。主模型冷启动合同/储能见 implementation.md。

本次预报覆盖之外的虚拟次日部分，接入本时刻可形成的 Q2 风格预测：负载目标日 lag-7（若已完成），PV 最近完整历史日。已覆盖区间使用本次已发布预报，未覆盖区间使用历史预测；标明拼接边界。在 τ+24 的边界保留该预报锚点，再与下一已定义的历史预测点连接；不外推读取下一次真实发布。记录尾部每点数据来源。

## 3. 每天固定历史源日，但误差随预报版本更新

预测负载：0 时用 D−7 同段；不足时用已完成日同时段均值。一天内该基准不变。Q3 光伏基准用当前已发布小时预报的重构值。

对历史日 H，在当时信息下保存四个发布版本重构的当日剩余曲线。对应残差：

`eps_L[H,t] = L_actual[H,t] - Lhat_0[H,t]`；

`eps_P[H,tau,t] = P_actual[H,t] - Phat[H,tau,t]`，仅定义 `t >= tau*6` 的当日剩余段。

只有 H 完成后才能把其当日各版本残差入库。若另存预报完整 24 小时的残差，跨日目标须全部实现后才可使用；不能按发布日已结束就视作全部成熟。主算法只使用上述“历史当日剩余段”残差，避免此漏洞。

0 时从同负载预测方法的最近 31 个已完成源日中按日期均匀取最多 8 天，所有日内阶段使用**相同源日 ID**。匹配不足时按已记录规则退到较少路径/已完成混合方法；无样本用单一点情景。不得通过事后分数挑当天最贴近真实未来的历史日。

τ 时的每个源日 H 生成：

`L_s[t] = max(0, Lhat_0[D,t] + eps_L[H,t])`；

`P_s[t] = max(0, Phat[D,tau,t] + eps_P[H,tau,t])`。

同一 H 配对负载和光伏，保留时间相关性。非负截断后重新计算净负荷误差，不继续使用截断前的 eps。权重均等、和为 1。

这不是“保持 0 时那八条光伏路径完全不变”：信息版本、误差尺度和实际 SOC 都更新；不做的是小样本最近邻重新挑历史日期。不能把 Q2 的 lag-1 光伏残差直接叠在附件 3 最新预报上。

## 4. 储能反馈的参考基准冻结，避免更新时产生假跳变

全日统一参考 `Nhat0[t]=(Lhat0[t]-Phat0[t])/6`。观测误差始终 `eps_obs[t]=(L_actual-P_actual)/6-Nhat0[t]`。

τ 时优化的情景特征按同一个 0 时基准计算：当前情景净负荷减 Nhat0；前 6 段均值使用真实已完成前缀与情景剩余后缀拼接。不能一半误差相对旧预报、一半相对新预报。

“本次最新预测版本”和“当前正在执行的规则训练版本”分别记录；若求解失败或保留原规则，两者可能不同，不能篡改旧规则的版本标签。

## 5. 因果性验收

必须在优化器调用前截断数据，而非把全年数组传入再承诺不用。0 时能看本次预报中未来目标值，这是合法预报；不能看未来实际或未来发布时间的真实预报。

扰动测试分别改变：尚未发布预报、当前段实际、后续段实际、次日实际、历史已完成数据。要求前四类不改变当时合同决策；可用历史或已发布预报在有辨识力的人工例中应影响候选决策。当前实际允许影响当段物理响应，不能因此回写合同。比较预测/情景/稀疏矩阵哈希优先；限时 MILP 的偶发解差异不能被误判为信息泄漏或拿来掩盖泄漏。
