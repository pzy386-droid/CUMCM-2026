## 主解释与备选解释必须分开

| 项目 | 本版主解释 | 限制/备选 |
|---|---|---|
| kW 数据 | 输入时间为区间右端标签，功率为区间代表值，乘 1/6 得 kWh | 是离散化假设，不是已证实的采样机制 |
| 当前观测 | 合同决策只看已完成段；实际执行可响应当前段代表值 | 如采用末端采样后才可用，须另做滞后一段敏感性 |
| 效率 | 充电、放电分别 0.9，母线侧电量 | 不是往返 90%；此口径与 Q1/Q2 一致 |
| SOC | 1/1 从 6000 连续运行；仅 Q1 明确日循环 | 禁止每天或 2/1 复位，受控实验除外且单独标识 |
| 未利用合同 | 仍付款，可无偿不利用，无售电收入 | 富余是总未利用量，不能一概叫弃光 |
| 减购结算 | 原计划款保留，减购再付 0.5p | 题面未明说退款；退款后另付违约金版本单独重优化、单独报告 |
| 多次修订 | 各交付段最终有效量相对 0 时原合同结算一次 | 题面未明确逐次收费；不允许两种口径混算 |
| 交易价格 | 对应供电区间附件 1 电价 | 不能用 6 时一个价格给全部未来区间计费 |
| Q3 原合同 | 必须由 Q3 的 0 时预报与历史生成 | 不能将 Q2 全年合同直接拷来冒充 Q3 正式日前结果；只可用于标明的反事实 |
| 预报以外信息 | 历史负载预测仍用 lag-7，日内保持该负载预测基准 | 不把当前日未来负载传给优化器 |

主结算且额外合同可免费不利用时，完整物理策略集中减购不占优。本版明确选 `a>=g0` 的不减购策略类；它不会阻止使用预报，因为预报还影响增购与储能。限制了反馈规则后的 MILP 不能借此宣称“不减购一定是其全局最优”。备选退款版本解除 `a>=g0`，允许 `a>=0`，并完整执行自己的储能和账本。

必须登记：原融合方案与本版差异、所有解释开关、实际解析的策略参数、实际求解器参数。不能仅靠配置中的策略名称判断实验相同。
