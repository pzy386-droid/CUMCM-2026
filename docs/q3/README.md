## 与原融合方案的关系

保留物理模型、联合历史日残差、共享储能规则、非对称调整收费、真实 SOC 连续、虚拟次日价值、唯一账本和预报价值分解。

本版明确作两项工程修订：

- 不复用 Q2 的“按当日残差前缀最近邻重新挑选 8 天”；固定当天历史源日，按发布时刻采用对应版本的历史预报误差。固定的是历史日期，不是冻结 0 时光伏误差。
- 原融合方案式 (12) 同时规划未来预报发布后的仿射合同修订规则。本版主实现改为**每次发布时，直接联合优化当前可提交的剩余合同与储能规则**，阶段内采用“假设本次方案延续至日末”的继续执行近似。下一次预报真正发布后再重算。不在 0 时读取未来真实预报，也不宣称已实现式 (12) 或严格多阶段最优。

这是为减少模型维度和语义错误作出的明确取舍。它可能低估未来改单机会，日前计划可能偏保守；必须以控制实验评价。未来合同仿射规则仅列为后续增强，不与主实现混用，更不能完成全年后为了叙事偷偷换算法。

Q2 的 A 仍作为独立工程参照；Q3 不因 Q2 某种日内重选变差而删除题给 6/12/18 时预报。更多信息没有保证让受限、限时求解的算法在每个历史样本上更省钱。
