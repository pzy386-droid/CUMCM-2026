## 3. 题面没有明确规定的内容：必须登记

- **未来价格可知性**：题目给出全年实际价格，但没有说明它在每天 0 时已全部公布。主结果采用未来价格未知、历史因果预测；“当天价格 0 时已知”作为单独的解释敏感性，不能混入主结果。它是价格信息参考，非自动成立的最优费用下界。
- **Q4-2 的附件 3 权限**：题目整体列出附件 3，同时要求“对应问题 2”。主版按继承问题权限解释，Q4-2 不使用附件 3，Q4-3 使用。另预设 `q4_2_with_pv0` 解释敏感性：仅给 Q4-2 当天 0 时预报、仍不得改约；至少做一月配对预检并说明差异，不能把这项假设隐去。
- **结算价格**：继承原融合方案，以供电区间实际价格作为该区间计划、调整和应急费用的基准；不是签约时的一个现货价覆盖全部未来区间。原题未给远期合约报价曲线，不虚构一套锁价市场。此解释在 Q4 比固定价时更重要，必须写入论文和元数据。
- **调整结算**：主版原计划款不退款，最终有效量相对 0 时原计划只结算一次；退款口径作为独立敏感性。不得悄悄改成相对上次修订逐次收费。
- **实时观测**：十分钟代表功率/价格在执行本段时可观测；合同提交先于本段观测。它是离散化假设，不把右端采样值无说明提前使用。
- **执行策略限制**：不应急充电、不放电弃电沿用原方案，属于选定策略类，不是题目明示硬约束。特别是波动价格下，不能声称应急充电在所有情况下都不经济；如放宽，必须单独命名、另写一致的优化与执行器，不暗中改变主方案。
