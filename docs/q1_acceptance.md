# Q1验收

负责人：方案与审查方。fable不得自行改核验器以通过检查。

## 自动检查
- 原始输入和模板SHA-256与manifest一致，144点时间端点连续。
- 账本输入p、L、PV逐行等于附件1，时间从00:00到24:00。
- 单段能量平衡、储电动态、上下界、初末6000、跨行S连续。
- 每段c/d≤5000/6，非负、有限；无同时充放电，无放电后弃用。
- 费用逐段p*g及日合计正确；summary全精度一致；solver状态与gap检查。
- 独立LP参考下界不超过候选费用；候选可行且达到下界才在本版本标记“达到独立参考最优值”。
- result1两表尺寸/表头/标签/值与账本一致；源模板未改。
- 144行模板映射与真实原件逐格核对。
- CSV、JSON和xlsx出现NaN/Inf、缺段、重复段或舍入导致物理不守恒，一律失败。
- 有错误时退出码非0；无结果时不会写“通过”。

## 人工审查
- 读取实现代码：矩阵系数与索引、变量界、互斥、求解状态处理。
- tables_q1.md与账本六个指定段核对，4小时块是24段。
- 图的单位、正负方向和首末点；不要将分段变化硬讲成“两充两放”。
- 不将理论下界或独立参考文件当成fable正式实现的成果。
- 干净环境按README命令重跑；检查提交哈希和输出版本。
- 不在审查未完成时标记accepted或合并main。

## 本轮负向测试
对独立核验器使用可行参考账本，再故意加入单位放大、时间错位、效率/SOC破坏、非有限数、汇总错误、同时充放电等，确认能够拒绝。工作簿导出测试在fable提交后执行。
