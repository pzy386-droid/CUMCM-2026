# 数据与因果信息合同

## 原始材料及时间

附件2两个表为“小区负载”“光伏发电实际功率”，均为366行×145列：首行为日期/144时间标签，后365行对应2025全年。
附件1只取144个价格。原始文件完整性由data/manifest.json核对，不覆盖源文件。

输入00:10是第一段的右端代表标签；内部第一段00:00—00:10，末段23:50—24:00。
这属于离散化解释，要在论文说明，不声称原题明确给出区间平均值。
实时执行假定区间代表值在该区间内可观测且保持不变；合同在0时不能观察当天未来实际值。严格末端观测、滞后一段执行可单列敏感性，不能混用。

## 接口强制隔离

回放环境可以载入全年文件，但决策层只能收到：
- 已完成日期历史；
- 本日已经完成的片段；
- 执行当前段时允许的当前观测；
- 当时的真实SOC、固定价格、既有合同、策略快照。

规划输入不能直接传入包含当天未来实际值的全年DataFrame。
用显式as_of时间对象/历史视图约束，而不是依赖调用者自觉不看未来列。
Q2不读取附件3或4。附件1负载/PV不能代替Q2历史预测。

## 默认预测

负载：D-7同一时段；不足7天时用已完成日期同时段均值。
光伏：D-1同一时段持续性。
1月1日无历史，按model.md冷启动；不假造2024年数据。

日内初版保留0时预测作为误差基准，只更新情景选择/权重与反馈参数。若未来增强预测基准更新，必须版本化并保证优化和执行一致。

## 残差必须当时可生成

每天先存当时预测，实际日完成后才追加：
epsilon_L[h,t]=actual_L[h,t]-forecast_as_of_h0[h,t]；
epsilon_PV同理。
记录日期、预测生成时刻、训练截止日、方法（lag-7或冷启动回退）及144点路径。
不能全年训练再回填历史残差；不能用未完成当天全日残差更新本日场景。

默认最多最近31个已完成日。优先匹配当前预测方法的历史残差；不足时明确标注回退来源。
取最多8条代表路径，初版可采用按日期排序后均匀覆盖的确定性抽取，实际不足8条用全部。
无残差时用单一点预测情景（误差为0），不要复制一条曲线并声称有8个独立样本。

同一个情景的负载/PV误差来自同一个历史日，同一条路径保留144段。
用当前预测加历史残差，再截断负载/PV至非负。
禁止把负载和PV分别随机抽取，禁止144段独立白噪声。
等权为初始默认，权重来源、选中日期、候选窗口、随机种子均留档。

6/12/18时可以只依据已观测误差前缀与历史前缀的相似程度重选路径或加权，不能用未观测后缀选“最像今天”的情景。
距离尺度只来自当前已可见历史，不能用全年极值归一化。

## 终端日预测

当前D日0时可知D-1整日，不能用D整日预测D+1。
负载优先目标日往前7天的已知曲线；若不可得用已完成日同时段均值。
PV初版用最近一个完整已知日曲线，D日0时即D-1；同日后续更新仍不能拼入D未来片段。
12月31日向2026年1月1日做预测不等于知道2026年实际值。

## 参数与公平性

固定默认8情景、2维反馈、31日窗口、L1预算2；后续选择仅凭已有历史验证。
一月调参可用于二月以后，但一月真实状态应由当时已规定的默认策略运行得到，不得用月末参数倒回去重跑一月、制造新期初SOC。
不能以全部334天费用选赢家后声称严格样本外。

保留全年数据诊断与预测可用信息的区别：附件1近似全年均值是材料诊断，不允许Q2用全年附件2拟合早期预测。
